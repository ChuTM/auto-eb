# Security Policy

## Supported Versions

We actively maintain AutoEB and patch security vulnerabilities to ensure a safe automation experience. Please ensure you are always running the latest version of the userscript.

| Version | Supported          |
| ------- | ------------------ |
| 1.6.x   | :white_check_mark: |

> **Note:** Because AutoEB operates directly within your browser context via Tampermonkey/Violentmonkey, running outdated versions may expose you to breaking changes or security risks if the underlying LMS platform updates its authentication mechanisms.

---

## Reporting a Vulnerability

If you discover a security vulnerability within AutoEB (such as data leaks, token exposure, or insecure credential handling), please **do not open a public GitHub issue**. Instead, help us protect the community by reporting it responsibly.

### How to Report
Please send an email to the maintainer at **alphabrate@gmail.com** (or contact via the preferred channel listed on ChuTM's GitHub profile) with the following details:
* A brief description of the vulnerability.
* Steps to reproduce the issue (and a proof-of-concept script/screenshot if applicable).
* The potential impact of the vulnerability.

### What to Expect
* **Acknowledgement:** You can expect an initial response within **48 hours** to acknowledge receipt of your report.
* **Status Updates:** We will keep you updated at least once every 5 days while we investigate and work on a fix.
* **Resolution:** If the vulnerability is accepted, we will coordinate a patch release. Once the fix is live, you will be credited for the discovery in our release notes (unless you prefer to remain anonymous).
